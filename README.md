# NavigatorMAX
Умный навигатор кружков и секций для детей и родителей. Чат-бот в MAX подбирает программы дополнительного образования по запросу на естественном языке с учётом интересов, возраста, расписания, местоположения и стоимости. Запись в кружки происходит через Навигатор дополнительного образования
